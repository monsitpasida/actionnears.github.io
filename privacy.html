นโยบายความเป็นส่วนตัว

Action Nears Bot · ปรับปรุงล่าสุด 17 พฤศจิกายน 2569

นโยบายนี้อธิบายว่า Action Nears Bot ("บอท") เก็บ ใช้ และดูแลข้อมูลอย่างไร บอทเป็นเครื่องมือภายในสำหรับทีมงาน ใช้งานผ่าน LINE

ข้อมูลที่เก็บ

  • ข้อมูลบัญชี LINE: LINE user ID และชื่อที่แสดง เพื่อระบุตัวผู้ใช้และตรวจสิทธิ์
  • ข้อมูลการสมัคร: ชื่อและตำแหน่ง/หน่วยงานที่ผู้ใช้กรอกตอนสมัคร
  • ข้อมูลงาน: ข้อความคำสั่งงาน โปรเจค งาน โน้ต และประวัติบทสนทนาล่าสุด (เก็บไม่เกิน 40 ข้อความต่อห้อง)
  • ไฟล์: รูป วิดีโอ เสียง และไฟล์ที่ผู้ใช้ที่ได้รับอนุมัติส่งในแชทที่มีบอทอยู่

การใช้ข้อมูล

  • บันทึกและติดตามงานของทีม สรุปความคืบหน้า และส่งการแจ้งเตือนใน LINE
  • ข้อความคำสั่งงานจะถูกส่งไปประมวลผลด้วยบริการ AI (Anthropic Claude API) เพื่อเข้าใจคำสั่งและตอบกลับ
  • ไม่นำข้อมูลไปขาย โฆษณา หรือใช้เพื่อวัตถุประสงค์อื่นนอกเหนือจากการจัดการงานของทีม

การใช้ข้อมูลจาก Google

  • บอทขอสิทธิ์ Google Drive เฉพาะ https://www.googleapis.com/auth/drive.file ซึ่งเข้าถึงได้เฉพาะไฟล์และโฟลเดอร์ที่บอทสร้างเอง
  • บอทใช้สิทธิ์นี้เพื่อสร้างโฟลเดอร์ อัปโหลด ย้าย และเปลี่ยนชื่อไฟล์ที่ทีมส่งในแชทเท่านั้น ไม่อ่าน แก้ไข หรือลบไฟล์อื่นใน Google Drive
  • การใช้และการส่งต่อข้อมูลที่ได้รับจาก Google APIs เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

การเปิดเผยข้อมูล

ข้อมูลจะถูกส่งต่อเฉพาะผู้ให้บริการที่จำเป็นต่อการทำงานของบอท ได้แก่ LINE (รับส่งข้อความ), Anthropic (ประมวลผล AI) และ Google (เก็บไฟล์) ไฟล์ใน Google Drive เปิดดูได้ตามการตั้งค่าการแชร์ของผู้ดูแลระบบ

การเก็บรักษาและความปลอดภัย

  • ข้อมูลงานเก็บในฐานข้อมูลบนเซิร์ฟเวอร์ของผู้ดูแลระบบ
  • เข้าถึงได้เฉพาะผู้ใช้ที่ได้รับอนุมัติ ผู้ดูแลระบบระงับสิทธิ์ผู้ใช้ได้ตลอดเวลา

สิทธิ์ของผู้ใช้

ผู้ใช้ขอดู แก้ไข หรือลบข้อมูลของตนเองได้โดยติดต่อผู้ดูแลระบบ และยกเลิกสิทธิ์ Google Drive ได้ที่ myaccount.google.com/permissions

ติดต่อ

หากมีคำถามเกี่ยวกับนโยบายนี้ กรุณาติดต่อผู้ดูแลระบบ Action Nears ทางอีเมลที่ระบุในหน้าขออนุญาตของ Google
